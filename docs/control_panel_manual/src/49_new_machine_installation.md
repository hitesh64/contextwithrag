# 49. Installing and Commissioning a New Machine in the Plant

When a new machine is bought, or an existing one is moved, the maintenance department manages the installation so that the machine is safe, accurate and maintainable from the first day.

## 49.1 Before the machine arrives

| Item | Responsible | Notes |
|---|---|---|
| Layout position and floor marking plan | Production, maintenance | Space for operation, loading, maintenance access (at least 800 mm around for service, more for doors of cabinets) |
| Foundation | Civil contractor as per maker's drawing | Concrete grade, thickness, anchor bolt positions; press brakes and turret punches often need dedicated foundations with isolation |
| Power supply | Electrical | Cable size for the machine's rated power and starting, dedicated feeder in the bay PDB with breaker per maker, isolation transformer or stabiliser for CNC if required |
| Earthing | Electrical | Two earth connections to the plant grid |
| Compressed air | Maintenance | Line size, drop with FRL and lockable isolation valve at the machine |
| Water / chiller / gas | Maintenance | As per machine requirements |
| Lifting and rigging plan | Maintenance with rigging contractor | Weight, lifting points, crane or rollers, path from gate to position |
| Risk assessment | Safety officer, maintenance | Hazards of the new machine; guarding, LOTO points, PPE |

## 49.2 Unloading and positioning

- Use the maker's lifting points and the rigging plan; never lift by covers, guards or the control cabinet.
- Move heavy machines on skates or rollers only on the planned path; protect floors and trenches.
- Position on the foundation; fit anchor bolts or levelling pads as per the maker.

## 49.3 Levelling

Accurate machines (press brake, turret punch, laser, busbar machine) must be levelled with a precision level (0.02 mm per metre) at the points given by the maker. Re-check levelling after one month (foundations settle) and then yearly.

## 49.4 Connection and first start

1. Check the supply voltage, phase sequence and earth before connecting.
2. Connect the power cable to the machine's main isolator, with correct gland and torque.
3. Connect air, water, gas as required; pressure test the connections.
4. Fill oils and coolants with the specified grades (often shipped empty).
5. With the maker's engineer: first power on, check of safety functions (emergency stops, interlocks, light curtains), axis references, hydraulic start.

## 49.5 Acceptance tests

The machine is accepted only after these tests, recorded in the machine acceptance report:

| Test | Example |
|---|---|
| Safety functions | All emergency stops, guards, light curtains, two-hand controls, LOTO points verified |
| Accuracy | Test parts as per the purchase specification (e.g. punch a test sheet and measure; bend test parts along the full length; laser cut test geometry) |
| Capacity | Maximum thickness and length cut / bent / punched |
| Speed and cycle time | As per specification |
| Noise | Measured at the operator position |
| Documentation | Manuals, electrical and hydraulic diagrams, spare parts list, software backups, CE / safety declarations as applicable |
| Training | Operators and maintenance staff trained by the maker; training record |

## 49.6 Registering the machine

1. Assign an asset code (next free number with the machine type prefix) and paint it on the machine.
2. Create the asset record and history card (Chapter 36.7).
3. Write the machine chapter of this manual (same structure as Chapters 6 to 15) and the daily check sheet (Appendix B), and add the machine to the master PM schedule (Chapter 24.3), the lubrication chart (Chapter 29.2.2), the spare parts list and the compliance register if applicable.
4. Add the machine's alarm codes to Appendix A through its chapter.
5. Add the machine to the skill matrix and train operators to level 2 before production.
6. Make the first backups of software and parameters.

## 49.7 Moving an existing machine

Moving a machine is treated like a new installation: foundation, levelling, connection, safety function tests and an accuracy check before production. Before moving, record the machine's accuracy and condition so that any change caused by the move can be identified.

## 49.8 Decommissioning

When a machine is taken out of use: isolate and disconnect all energies permanently, drain oils (disposed as hazardous waste), remove or neutralise stored energy (accumulators, springs), remove the asset from PM schedules, and update this manual.

!! HINGLISH: Nayi machine aane se pehle foundation, bijli ki cable aur earth, air, layout aur risk assessment taiyar karo. Machine ko sirf maker ke lifting point se uthao. Precision level se level karo aur ek mahine baad dobara check. Safety function, accuracy aur capacity ke test pass hone ke baad hi machine accept hoti hai. Asset code, history card, check sheet, PM schedule, manual ka chapter aur operator training sab update karo.
