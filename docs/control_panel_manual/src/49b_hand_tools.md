# 50. Hand Tools and Power Tools: Correct Use

Many injuries in panel shops are caused not by machines but by hand tools and portable power tools. This chapter sets the rules for their selection, use and care.

## 50.1 General rules

- Use the right tool for the job; never use a screwdriver as a chisel or a spanner as a hammer.
- Inspect every tool before use: no cracks, loose heads, damaged insulation, mushroomed chisel heads, worn jaws.
- Keep tools clean and in their marked place (shadow board or tool kit).
- Report damaged tools and take them out of use (red tag).
- Carry sharp tools with the edge covered; never in pockets.
- Personal tool kits are checked monthly (Chapter 4.6).

## 50.2 Hand tools

| Tool | Correct use | Common misuse and hazard |
|---|---|---|
| Screwdrivers | Tip size matches the screw; hold the work on the bench, not in the hand | Slipping tip into the hand; using as a lever or chisel |
| Insulated screwdrivers (1000 V) | For any work in panels; insulation undamaged | Insulation cut or melted: replace |
| Spanners and sockets | Correct size; pull towards you; ring spanners preferred | Open-ended spanner slipping; extension pipes on spanners |
| Torque wrenches | Set value, pull smoothly until click; store at lowest setting; never use to loosen bolts | Using as a breaker bar damages calibration |
| Pliers and side cutters | Cutting wires within their rated size; insulated for electrical work | Cutting hardened wire or steel; using as spanner |
| Wire strippers | Adjusted for wire size; check for nicked strands | Knife stripping (nicks strands and fingers) |
| Crimping tools (ratchet) | Matching die for terminal; complete the ratchet cycle | Half crimps; wrong die |
| Hydraulic crimping tool | Correct hexagonal die; full pressure until relief valve clicks | Wrong die, partial crimp |
| Hacksaw | Blade teeth forward, tension correct, 24 TPI for thin sheet and conduit | Loose blade breaks |
| Files | Fitted with handles | Tang (pointed end) stabs the palm without handle |
| Hammers | Head tight; soft-faced hammer for machined and painted surfaces | Loose head flies off |
| Chisels and punches | Heads ground free of mushrooming | Flying fragments from mushroomed heads |
| Utility knife | Retractable blade, cut away from the body | Cuts to hands and legs |
| Deburring tool | Swivel blade, small strokes | - |
| Measuring tools (vernier, micrometer, tape) | Clean, zero-checked, calibrated | Dropped tools lose accuracy: report |

## 50.3 Portable power tools

| Tool | Rules |
|---|---|
| Electric drill | Clamp the work; correct drill size and speed; do not hold small parts by hand; remove chuck key before starting; no gloves near the rotating chuck with loose cuffs |
| Cordless screwdriver | Clutch set for the screw type to avoid stripping threads in PEM nuts; correct bit |
| Angle grinder | Guard fitted; disc rated for the grinder speed; two hands; face shield; never use a cutting disc for grinding on its side (Chapter 11.4.2) |
| Orbital sander | Dust extraction; correct disc grit |
| Jigsaw / nibbler | For late cut-outs only with supervisor approval; clamp the work; protect devices from swarf |
| Hole punch (hydraulic knock-out punch) | Preferred over drilling for round holes in gland plates; no swarf; correct die set |
| Hot air gun | Stand when not in use; keep away from flammable material; let it cool before storing |
| Heat gun for sleeves | Keep moving; nozzle 50 to 100 mm from the sleeve |
| Vacuum cleaner | For cleaning panels and booth; explosion-protected type for powder booth |

### 50.3.1 Electrical safety of portable tools

- Use tools on 230 V only through sockets protected by 30 mA RCCBs; double-insulated (class II) tools preferred.
- Inspect plug, cable and switch before use; damaged cable = tool out of use.
- Portable appliance test (insulation and earth continuity) every 6 months; test label with due date.
- Do not carry tools by the cable or pull the plug by the cable.
- Extension leads: fully unwound (coiled leads overheat), with RCCB.

## 50.4 Drilling near devices

Swarf from drilling is a major cause of failures in panels. If drilling is unavoidable after devices are fitted:

1. Get supervisor approval.
2. Cover all devices below and around the hole with plastic sheet and tape.
3. Use a magnetic swarf collector or a vacuum cleaner at the drill tip.
4. After drilling, deburr the hole, remove the cover carefully, and vacuum the area.
5. Touch up the bare metal edge with paint (except earth points).

Prefer hydraulic knock-out punches (no swarf) for round holes and remove the plate from the panel for larger cut-outs.

## 50.5 Ladders and working at height

- Use step ladders with platform and handrail for work on tall panels (2200 mm plus base); never stand on the panel roof or on crates.
- Ladder inspection before use: feet, rungs, locking stays.
- Work above 1.8 m needs a permit (Chapter 3.11), and fall protection as specified.
