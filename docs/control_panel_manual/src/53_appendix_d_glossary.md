# Appendix D. Glossary

| Term | Meaning |
|---|---|
| Accumulator | Pressure vessel storing hydraulic oil under gas pressure; holds energy after the pump stops |
| Activation | Pre-treatment stage that seeds fine phosphate crystals before phosphating |
| Air bending | Bending where the sheet touches only the punch tip and the die shoulders; angle set by depth |
| Alarm | Message from a machine controller that a condition is outside its limits |
| Anvil | Lower tool of the insertion press supporting the sheet under the fastener |
| APFC | Automatic power factor correction; switches capacitor steps to keep the power factor high |
| Arc chute | Part of a breaker that splits and cools the arc when contacts open |
| Arc flash | Explosive release of energy from an electric arc; causes burns and blast injuries |
| Assist gas | Gas blown with the laser beam to remove molten metal (oxygen, nitrogen, air) |
| Auto-index | Turret station that can rotate a tool to any angle |
| Back gauge | CNC-positioned stop behind the tool that sets flange length or strip width |
| Back-ionisation | Powder coating defect from excessive charge build-up on the film |
| Backlash | Play in a mechanical drive, for example between ball screw and nut |
| Ball screw | Screw with recirculating balls for precise linear motion |
| Bend deduction | Amount subtracted from the sum of outside dimensions to get the flat length |
| BOM | Bill of materials: list of all parts with make, type and quantity |
| Bootlace ferrule | Tube crimped on stranded wire end for screw or spring terminals |
| Breaking capacity | Highest fault current a breaker can interrupt (Icu, Ics) |
| Burr | Sharp ridge of metal left at a cut edge |
| Busbar | Rigid copper or aluminium conductor carrying the main current |
| Bus coupler | Breaker connecting two busbar sections |
| Cavitation | Formation and collapse of vapour bubbles at a pump inlet; noise and damage |
| Clearance (electrical) | Shortest distance through air between conductive parts |
| Clearance (tool) | Gap between punch and die, or between shear blades |
| Coil voltage | Voltage at which a contactor or relay coil is designed to operate |
| Condition monitoring | Measuring the condition of equipment (vibration, temperature, oil) to plan maintenance |
| Contactor | Electrically operated switch for frequent switching of power circuits |
| Creepage distance | Shortest distance along the surface of insulation between conductive parts |
| Crimp | Cold-pressed joint between a terminal and a conductor |
| Crimp height | Measured height of a crimped barrel, used to check crimp quality |
| Crowning | Compensation of beam deflection on a press brake for an even angle along the length |
| Cross-cut test | Adhesion test of paint with a grid of cuts and tape |
| CT | Current transformer: gives a secondary current proportional to the primary current |
| Cure | Chemical hardening of powder coating in the oven |
| Cyclone | Separator that removes powder from the booth exhaust air by centrifugal force |
| DC bus | Internal DC circuit of a VFD with capacitors that stay charged after switch-off |
| Dead time | Short pause between star and delta contactor in a star-delta starter |
| Degree of protection | IP code: protection of an enclosure against solids and water |
| Design verification | Proof (by test, calculation or comparison) that a panel design meets IEC 61439 |
| DFT | Dry film thickness of paint, in microns |
| Dielectric test | Power frequency withstand (HV) test of insulation |
| DIN rail | Standard 35 mm metal rail for mounting devices |
| Discrimination | See selectivity |
| DOL | Direct on line starter: connects the motor directly to the supply |
| Draw-out | Breaker or module that can be withdrawn from its cradle |
| Dross | Molten metal stuck to the underside of a laser cut |
| Dropper | Vertical busbar feeding the functional units of a section |
| Earth continuity | Low resistance path from exposed metal to the protective earth terminal |
| EDM (safety) | External device monitoring: feedback that controlled contactors have opened |
| Electrode (welding) | Copper alloy tip that carries current and force in spot welding |
| Encoder | Sensor that measures position or speed of a motor or axis |
| Expulsion | Molten metal ejected from a spot weld |
| FAT | Factory acceptance test witnessed by the customer |
| Faraday cage effect | Difficulty of coating inside corners because of the electric field shape |
| Feeder | Outgoing circuit of a panel |
| Ferrule (marker) | Printed sleeve showing the wire number |
| First-off | First part made after a set-up, fully checked before the batch |
| FLC | Full load current of a motor |
| Fluidising | Making powder behave like a liquid by passing air through it |
| Form of separation | Internal separation arrangement of a panel (Form 1 to 4b) |
| FRL | Filter, regulator, lubricator unit for compressed air |
| Functional unit | Part of a panel with all the devices of one function (one feeder) |
| GA drawing | General arrangement: views and dimensions of the panel |
| Gland plate | Plate with holes for cable glands |
| Gooseneck punch | Press brake punch shaped to clear return flanges |
| Half-split method | Fault finding by testing in the middle of a chain to halve the search each time |
| Hem | Flange folded flat back onto the sheet |
| HMI | Human machine interface: touch screen of a machine or panel |
| Hold-down | Pad that clamps the sheet before a shear cut |
| Holding contact | Contact that keeps a contactor energised after the start button is released |
| Icw | Rated short-time withstand current of busbars (for example 50 kA for 1 s) |
| IDMT | Inverse definite minimum time: relay characteristic where trip time falls as current rises |
| Interlock | Arrangement preventing a dangerous or wrong operation |
| IR test | Insulation resistance measurement with a DC test voltage |
| Job card | Document travelling with a job, recording operations and inspections |
| K-factor | Position of the neutral axis in a bend as a fraction of thickness |
| Kerf | Width of material removed by a cut |
| Knock-out | Partly punched hole held by tabs, removed when needed |
| Light curtain | Safety device of light beams that stops a machine when interrupted |
| LOTO | Lockout and tagout: isolating and locking energy sources before work |
| Louvre | Formed ventilation opening in sheet metal |
| LSIG | Long-time, short-time, instantaneous and ground fault protection functions |
| Masking | Covering areas that must stay free of paint |
| MCC | Motor control centre |
| Micro-joint | Small uncut tab holding a part in the sheet skeleton |
| MPCB | Motor protection circuit breaker |
| MTBF / MTTR | Mean time between failures / mean time to repair |
| Muting | Temporary, controlled suppression of a safety device at a safe point of the cycle |
| Near miss | Event that could have caused injury or damage but did not |
| Nesting | Arranging parts on a sheet for cutting with minimum waste |
| NCR | Non-conformance report |
| Nibbling | Cutting a contour with many overlapping punch hits |
| Nugget | Fused zone of a spot weld |
| Overload relay | Device that trips a motor circuit on sustained overcurrent |
| PE | Protective earth conductor |
| Peel test | Destructive test of a spot weld by peeling the sheets apart |
| Phosphating | Forming a zinc phosphate conversion coating on steel before painting |
| PLC | Programmable logic controller |
| Polarisation index | Ratio of 10-minute to 1-minute insulation resistance |
| Power factor | Ratio of real power (kW) to apparent power (kVA) |
| Pre-treatment | Cleaning and chemical conversion of metal before painting |
| Proportional valve | Hydraulic valve whose opening is controlled continuously by an electrical signal |
| Punch list | List of open defects to be corrected |
| Rake angle | Angle of the upper shear blade relative to the lower blade |
| RCCB | Residual current circuit breaker |
| Relief valve | Valve limiting the maximum pressure of a hydraulic system |
| Repositioning | Re-gripping a sheet to punch beyond the axis travel |
| Root cause | The underlying reason for a failure, whose removal prevents recurrence |
| Routine verification | Tests done on every panel (IEC 61439 clause 11) |
| Selectivity | Only the breaker nearest a fault trips |
| Servo valve | High-precision hydraulic valve used for position control |
| Shunt trip | Accessory coil that trips a breaker when energised |
| Shutters | Plates that cover busbar contacts when a withdrawable unit is removed |
| SLD | Single line diagram |
| Slug | Piece of metal punched out of the sheet |
| Soft starter | Thyristor device that reduces motor starting current |
| Spring-back | Opening of a bend after the bending force is removed |
| SPD | Surge protective device |
| Star-delta | Starter that starts a motor in star and runs it in delta |
| Stripper | Part that holds the sheet down while the punch withdraws |
| Torque seal | Paint mark on a tightened bolt showing it was torqued |
| Turret | Rotating tool holder of a turret punch press |
| Type 2 coordination | Starter combination that remains usable after a short circuit |
| UVR | Under-voltage release |
| V-die | Lower press brake tool with a V-shaped opening |
| VFD | Variable frequency drive |
| Water-break test | Check of surface cleanliness: a clean surface holds a continuous water film |
| Wire kit | Prepared set of cut, stripped, marked and crimped wires for one panel |
