# Appendix B. Check Sheets and Forms

The check sheets below are the standard forms of the plant. Each daily check sheet is printed for one month (one column per day in the printed version) and kept at the machine. The operator ticks OK or writes NOK with a remark, and signs. Any NOK on a safety item stops the machine until maintenance has corrected it and the supervisor has signed.
